# MoviPass 🚌

Aplicación web para la gestión y venta de pasajes de transporte interprovincial en Ecuador.

> Proyecto grupal de **Manejo y Configuración de Software**, Carrera de Software, FISEI, Universidad Técnica de Ambato.

🌐 **Demo:** https://movipass.netlify.app
📦 **Repositorio del proyecto:** https://github.com/kmoyolema3929/MoviPass

## ¿Qué hace?
Permite a las cooperativas administrar buses, frecuencias y rutas, y a los usuarios buscar viajes, elegir asientos y comprar su boleto.

## Roles del sistema
| Rol | Función |
|---|---|
| Administrador | Crea cooperativas y su usuario gerente |
| Cooperativa | Gestiona buses, frecuencias, rutas y precios |
| Oficinista | Vende boletos y aprueba comprobantes de pago |
| Usuario final | Busca viajes, compra y consulta su historial |
| Usuario bus | Valida boletos y cobra en ruta |

## Tecnologías
HTML5 · CSS3 · JavaScript · Bootstrap 5 · Supabase (PostgreSQL, Auth, Storage) · Git y GitHub (Gitflow)
